4
AI-Aware Services
llm-d intelligent routing, WVA autoscaling, KServe model serving
▾

llm-d (CNCF Sandbox, co-created by Red Hat, Google, IBM, CoreWeave, NVIDIA) is distributed inference middleware. Its Endpoint Picker (EPP) routes each request to the replica with the most relevant KV-cache already loaded via a KV-Cache Indexer that maintains a near-real-time block-key-to-pods mapping. llm-d adds three capabilities: (1) KV-cache-aware routing — directs requests to replicas that already have relevant context cached, avoiding redundant computation; (2) Disaggregated prefill/decode — separates compute-intensive prompt processing from memory-intensive token generation across different GPU pools; (3) Tiered prefix caching — reuses shared system prompts and tool definitions across requests, particularly valuable for agentic workloads chaining 10–20 LLM calls. WVA (Workload Variant Autoscaler) scales model replicas based on inference-specific signals: queue depth, KV-cache pressure, token throughput, latency percentiles.

3
Governance
Kueue quotas, fair-share scheduling, borrowing, preemption
▾

When 4 teams want 150 GPUs but only 100 exist, Kueue makes the allocation policy. Each team gets a nominalQuota (guaranteed entitlement), can burst via borrowing from peers’ unused capacity, and capacity is reclaimed via preemption. NUANCE: Kueue is not always needed. A dedicated inference cluster with a single tenant gets no value from admission control — it only adds latency.

2
GPU Mechanisms
MIG partitioning, DRA, time-slicing, device plugins
▾

MIG (Multi-Instance GPU) carves a single A100 or H100 into hardware-isolated partitions with dedicated memory bandwidth and compute cores. DRA (Dynamic Resource Allocation) replaces opaque nvidia.com/gpu: 1 requests with attribute-based claims. NVIDIA donated the DRA GPU driver to CNCF at KubeCon Europe 2026. DRA GA in RHOAI is targeted for 3.6/3.7.

GPU Fleet
Physical accelerators, topology, networking
▾

Physical GPUs are not fungible. An H100 with NVLink at 900 GB/s between 8 GPUs on a single NVSwitch domain is fundamentally different from 4+4 split across servers connected by InfiniBand. Node Feature Discovery (NFD) labels every node with hardware metadata — GPU model, memory capacity, PCIe generation, NUMA affinity.
