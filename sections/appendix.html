Rafay

Role-segmented dashboards and SKU Studio for GPU management. Strength: UX-first approach with clear persona separation. Tradeoff: narrower AI lifecycle coverage — focuses on infrastructure management rather than the full training-to-serving pipeline.

On-Premises (OpenShift) vs. Cloud-Managed (EKS / AKS / GKE)

DimensionOn-Premises / HybridCloud-Managed
GPU supplyFixed fleet, capital expenditureElastic, near-infinite on demand
Data residencyFull control, on-prem sovereigntySubject to cloud region policies
OperationsTeam manages GPU operators, drivers, upgradesManaged by cloud provider
PortabilitySame stack across environmentsCloud-specific GPU management tools
Cost modelCapEx + OpEx, amortizedOpEx only, spot/preemptible available
Tradeoff summary: Run:AI has a more mature GPU dashboard and hierarchical quota UX today. Cloud providers offer elastic scale. The Kueue-based approach trades dashboard maturity for multi-vendor support, Kubernetes-native primitives, and full AI lifecycle integration. Dashboard and scheduling explainability are on the RHOAI 3.6–3.7 roadmap.
